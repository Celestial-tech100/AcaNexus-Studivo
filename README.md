## 📖 Overview

AcaNexus : Studivo is a full-stack web application built to help students manage both their academic responsibilities and hostel life efficiently.

The platform combines productivity tools, academic management features, and hostel-oriented utilities into a single dashboard, reducing the need for multiple applications.

---

## 🎯 Problem Statement

Students often use separate applications for:

- Notes management
- Assignment tracking
- Study planning
- Expense tracking
- Hostel-related activities

Managing all these tasks across multiple platforms becomes inefficient and time-consuming.

**AcaNexus : Studivo** aims to solve this problem by providing a centralized student productivity ecosystem.
